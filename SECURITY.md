# shell4 security policy

## supported versions

| version     | status | end of support   |
| ----------- | ------ | ---------------- |
| v0.3.x      | ✅     | 19 sep 2026      |
| v0.2.x      | ✅     | 29 aug 2026      |
| v0.1.x      | ✅     | 29 aug 2026      |

the latest nightly/pre builds are also supported.

## reporting a vulnerability

only [GitHub Private Vulnerability Reporting](https://github.com/barsik0396/shell4/security/advisories) is used.

## credits

reporters will be credited in [`credits.md`](/CREDITS.md), unless they request anonymity.
