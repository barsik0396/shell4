# shell4 Privacy Policy

Last updated: August 1, 2026

## What is collected

shell4 sends anonymous telemetry events to a statistics collection server. The following events are sent:

- `/download`: on download
- `/install`: on install
- `/run`: on first run
- `/uninstall`: on uninstall

Each event contains only:

- `platform`: operating system (e.g. `linux`, `macos`, `windows`)
- `arch`: CPU architecture (e.g. `x86_64`, `arm64`)

## What is NOT collected

- File names, command contents, or command history
- Shell session contents
- Any user identifiers (email, name, account, etc.)
- Geolocation

## IP addresses

Since telemetry is sent over the network, the server technically receives the sender's IP address as part of the standard network request. This address is not used to identify the user and is not linked to the submitted events.

## Disabling telemetry

Telemetry cannot currently be disabled. The collected events are limited to technical data (`platform`, `arch`) and are not considered personal data.

In the future, an option to disable telemetry is planned for more sensitive actions.

## Use of data

Collected data is used solely to understand which platforms and architectures shell4 is used on, in order to prioritize support and development. Data is not shared with or sold to third parties.

## Changes to this policy

This policy may be updated as shell4 evolves (e.g. when new telemetry events are added or an opt-out option is introduced). The latest version is always available in the project's repository.
